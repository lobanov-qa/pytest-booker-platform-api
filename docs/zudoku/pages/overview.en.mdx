    localStorage.setItem("preferred-language", lang);

This document describes the **real behavior** of each microservice API in [restful-booker-platform](https://github.com/mwinteringham/restful-booker-platform). All status codes and response formats are verified via direct curl requests.

> 🔍 **API verification**:
> - Swagger/OpenAPI: `http://localhost:<port>/<service>/v3/api-docs`
> - Health: `http://localhost:<port>/<service>/actuator/health`
> - Status: ✅ matches OpenAPI spec, ⚠️ differs from spec

---

## Authorization Notes

- **Token format**: string (e.g., `abc123`).
- **Obtaining**: `POST /auth/login` with body `{"username": "admin", "password": "password"}`.
- **Token is returned in `Set-Cookie`**, not in the response body.
- **Sending**: in header `Cookie: token=<value>`.

---

- **Base URL**: `http://localhost:3004`
- **Swagger**: `http://localhost:3004/auth/v3/api-docs`
- **Health**: `http://localhost:3004/auth/actuator/health`

## Service: Booking

- **Base URL**: `http://localhost:3000`
- **Swagger**: `http://localhost:3000/booking/v3/api-docs`
- **Health**: `http://localhost:3000/booking/actuator/health`

<div class="table-container">

| Method | Path | Purpose | Client | Auth? | Status | Notes |
|--------|------|---------|--------|:----:|--------|-------|
| GET | `/booking/unavailable` | Availability | `PublicBookingClient` | ❌ | **200** ✅ | Params: `checkin`, `checkout` |
| POST | `/booking/` | Create | `PublicBookingClient` | ❌ | **201** ⚠️ | Spec: 200. Real: 201 Created |
| GET | `/booking/summary` | Summary | `PublicBookingClient` | ❌ | **200** ✅ | Param: `roomid` |
| GET | `/booking/{id}` | Details | `PrivateBookingClient` | ✅ | **200** ✅ | — |

| DELETE | `/booking/{id}` | Delete | `PrivateBookingClient` | ✅ | **202** ⚠️ | Spec: 200. Real: 202 Accepted |

</div>

| Endpoint | Expected | Actual |
|----------|---------|--------|
| `POST /booking/` | 200 OK | **201 Created** |

| `GET /booking/-1` (negative ID) | 400 Bad Request | **404 Not Found** |

## Service: Room

- **Base URL**: `http://localhost:3001`
- **Swagger**: `http://localhost:3001/room/v3/api-docs`
- **Health**: `http://localhost:3001/room/actuator/health`

<div class="table-container">

| Method | Path | Purpose | Client | Auth? | Status | Notes |
|--------|------|---------|--------|:----:|--------|-------|
| GET | `/room/` | List all | `PublicRoomClient` | ❌ | **200** ✅ | Optional: `checkin`, `checkout` |
| GET | `/room/{id}` | Details | `PublicRoomClient` | ❌ | **200** ✅ | — |
| POST | `/room/` | Create | `PrivateRoomClient` | ✅ | **201** ✅ | Requires `roomPrice` >= 1 |
| PUT | `/room/{id}` | Update | `PrivateRoomClient` | ✅ | **202** ⚠️ | Spec: 200. Real: 202 Accepted |
| DELETE | `/room/{id}` | Delete | `PrivateRoomClient` | ✅ | **202** ⚠️ | Spec: 200. Real: 202 Accepted |

</div>

### Spec Deviations

| Endpoint | Expected | Actual |
|----------|---------|--------|
| `GET /room/9999` (not found) | 404 | **500 Internal Server Error** |
| `GET /room/0` (invalid ID) | 400 | **500 Internal Server Error** |
| `GET /room/-1` (negative ID) | 400 | **404 Not Found** |
| `POST /room/` field `roomPrice` | optional | **Required >= 1** |

### Serialization
- All fields in **camelCase** (roomName, type, roomPrice, roomid)
- `null` values for optional fields → 400. Uses `exclude_none=True`

## Service: Message

- **Base URL**: `http://localhost:3006`
- **Swagger**: `http://localhost:3006/message/v3/api-docs`
- **Health**: `http://localhost:3006/message/actuator/health`

<div class="table-container">

| Method | Path | Purpose | Client | Auth? | Status | Notes |
|--------|------|---------|--------|:----:|--------|-------|
| GET | `/message/` | List all | `PublicMessageClient` | ❌ | **200** ✅ | — |
| GET | `/message/count` | Count | `PublicMessageClient` | ❌ | **200** ✅ | — |
| POST | `/message/` | Create | `PublicMessageClient` | ❌ | **201** ⚠️ | Spec: 200. Real: 201 Created |
| GET | `/message/{id}` | Details | `PublicMessageClient` | ❌ | **200** ✅ | **Public**, no token needed |
| PUT | `/message/{id}/read` | Mark read | `PrivateMessageClient` | ✅ | **202** ⚠️ | Spec: 200. Real: 202 Accepted |
| DELETE | `/message/{id}` | Delete | `PrivateMessageClient` | ✅ | **202** ⚠️ | Spec: 200. Real: 202 Accepted |

</div>

### Spec Deviations

| Endpoint | Expected | Actual |
|----------|---------|--------|
| `GET /message/{id}` | requires token | **Public** |
| `GET /message/9999` (not found) | 404 | **500 Internal Server Error** |

### Schemas
- `MessageSchema` (full): messageid, name, email, phone, subject, description
- `MessageSummarySchema` (list): id, name, subject, read — field is `id`, not `messageid`
