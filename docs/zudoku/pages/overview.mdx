Документ описывает требования к авторизации для каждого эндпоинта согласно анализу **локально развернутых Swagger UI** и **официальной Postman-коллекции** к [restful-booker-platform](https://github.com/mwinteringham/restful-booker-platform).

> 🔍 **Важно о документации**:
> - Swagger UI доступен **только локально** после запуска сервисов через Docker.
> - Эндпоинты и схемы проверены по OpenAPI, генерируемому каждым микросервисом.
> - Дополнительно сверено с Postman-коллекцией.

## Важные замечания по авторизации

- **Формат токена**: строка (например, `abc123`).
- **Получение токена**:
  - `POST /auth/login` с телом `{"username": "admin", "password": "password"}`.
  - **Токен возвращается в `Set-Cookie`**, а не в теле (несмотря на OpenAPI).
  - Тело ответа — пустое.
- **Передача токена**:
  - Для всех последующих запросов: в заголовке `Cookie: token=<значение>`.
  - Для `/auth/validate` и `/auth/logout`: токен отправляется в теле: `{"token": "..."}`.
- **Жизненный цикл токена**: На удалённом сервере токен сбрасывается каждые 10 минут.
- **Примечание по клиентам**: `*` — клиент ещё не реализован.

## Сервис: Auth (Аутентификация)

- **Базовый URL**: `http://localhost:3004`
- **Swagger UI**: [http://localhost:3004/auth/swagger-ui/index.html](http://localhost:3004/auth/swagger-ui/index.html)
- **Проверка здоровья сервиса**: [http://localhost:3004/auth/actuator/health](http://localhost:3004/auth/actuator/health)

<div class="table-container">

| Метод | Путь              | Назначение         | Клиент             | Примечания |
|-------|-------------------|--------------------|--------------------|------------|
| POST  | `/auth/login`     | Создание токена    | `AuthClient` | Токен в `Set-Cookie`. Тело пустое. |
| POST  | `/auth/validate`  | Валидация токена   | `AuthClient` | Токен в теле: `{"token": "abc123"}` |
| POST  | `/auth/logout`    | Уничтожение токена | `AuthClient` | Токен в теле: `{"token": "abc123"}` |

</div>

## Сервис: Booking (Бронирования)

- **Базовый URL**: `http://localhost:3000`
- **Swagger UI**: [http://localhost:3000/booking/swagger-ui/index.html](http://localhost:3000/booking/swagger-ui/index.html)
- **Проверка здоровья сервиса**: [http://localhost:3000/booking/actuator/health](http://localhost:3000/booking/actuator/health)

<div class="table-container">

| Метод | Путь                   | Назначение                     | Клиент               | Требует аутентификации | Примечания |
|-------|------------------------|--------------------------------|----------------------|------------------------|------------|
| GET   | `/booking/unavailable` | Проверка доступности комнат  | `PublicBookingClient` | ❌ Нет | Обязательные параметры: `checkin`, `checkout` |
| POST  | `/booking/`            | Создание бронирования         | `PublicBookingClient` | ❌ Нет | OpenAPI не требует токен |
| GET   | `/booking/summary`     | Сводка по броням              | `PublicBookingClient` | ❌ Нет | Обязательный параметр: `roomid` |
| GET   | `/booking/{id}`        | Детали бронирования           | `PrivateBookingClient` | ✅ Да | Токен в `Cookie` |
| GET   | `/booking/`            | Все бронирования              | `PrivateBookingClient` | ✅ Да | Опциональный параметр: `roomid` |
| PUT   | `/booking/{id}`        | Обновление бронирования       | `PrivateBookingClient` | ✅ Да | Токен в `Cookie` |
| DELETE| `/booking/{id}`        | Удаление бронирования         | `PrivateBookingClient` | ✅ Да | Токен в `Cookie` |

</div>
