  function switchLanguage(lang) {
    localStorage.setItem("preferred-language", lang);

    const currentPath = window.location.pathname;
    let newPath;

    if (lang === "en") {
      newPath = currentPath.replace(/\\/overview(\\.(ru|en))?$/, "/overview.en");
    } else {
      newPath = currentPath.replace(/\\/overview(\\.(ru|en))?$/, "/overview");
    }

    if (currentPath === newPath) return;

    window.location.href = newPath;
  }

  function goToHome() {
    window.location.href = "/pytest-booker-platform-api/";
  }

  document.addEventListener("DOMContentLoaded", () => {
    const savedLang = localStorage.getItem("preferred-language") || "ru";
    const currentPath = window.location.pathname;
    const isEnglish = currentPath.includes("/overview.en");
    const activeLang = isEnglish ? "en" : "ru";

    if (savedLang !== activeLang) {
      localStorage.setItem("preferred-language", activeLang);
    }

    const buttons = document.querySelectorAll(".language-switcher button");
    buttons.forEach((btn) => {
      if (btn.dataset.lang === activeLang) {
        btn.classList.add("active");
      }
    });
  });

Документ описывает реальное поведение API каждого микросервиса [restful-booker-platform](https://github.com/mwinteringham/restful-booker-platform). Все статусы и форматы ответов проверены через curl.

> 🔍 **Проверка API**:
> - Swagger/OpenAPI: `http://localhost:<port>/<service>/v3/api-docs`
> - Health: `http://localhost:<port>/<service>/actuator/health`
> - Статусы: ✅ соответствует OpenAPI, ⚠️ отличается от спецификации

---

## Важные замечания по авторизации

- **Токен** — строка (например, `abc123`).
- **Получение**: `POST /auth/login` с телом `{"username": "admin", "password": "password"}`.
- **Возвращается в `Set-Cookie`**, не в теле.
- **Передача**: `Cookie: token=<значение>`.

## Сервис: Auth

- **Базовый URL**: `http://localhost:3004`
- **Swagger**: `http://localhost:3004/auth/v3/api-docs`
- **Health**: `http://localhost:3004/auth/actuator/health`

<div class="table-container">

| Метод | Путь | Назначение | Клиент | Статус | Примечания |
|-------|------|-----------|--------|--------|------------|
| POST | `/auth/login` | Вход | `AuthClient` | **200** ✅ | Токен в `Set-Cookie` |
| POST | `/auth/validate` | Валидация | `AuthClient` | **200** ✅ | Токен в теле: `{"token": "..."}` |
| POST | `/auth/logout` | Выход | `AuthClient` | **200** ✅ | Токен в теле: `{"token": "..."}` |

</div>

## Сервис: Booking

- **Базовый URL**: `http://localhost:3000`
- **Swagger**: `http://localhost:3000/booking/v3/api-docs`
- **Health**: `http://localhost:3000/booking/actuator/health`

<div class="table-container">

| Метод | Путь | Назначение | Клиент | Требует токен | Статус | Примечания |
|-------|------|-----------|--------|:----------:|--------|-----------|
| GET | `/booking/unavailable` | Доступность | `PublicBookingClient` | ❌ | **200** ✅ | Параметры: `checkin`, `checkout` |
| POST | `/booking/` | Создание | `PublicBookingClient` | ❌ | **201** ⚠️ | Спека: 200. Реальность: 201 |
| GET | `/booking/summary` | Сводка | `PublicBookingClient` | ❌ | **200** ✅ | Параметр: `roomid` |
| GET | `/booking/{id}` | Детали | `PrivateBookingClient` | ✅ | **200** ✅ | — |
| GET | `/booking/` | Все брони | `PrivateBookingClient` | ✅ | **200** ✅ | Опциональный: `roomid` |
| PUT | `/booking/{id}` | Обновление | `PrivateBookingClient` | ✅ | **200** ✅ | — |
| DELETE | `/booking/{id}` | Удаление | `PrivateBookingClient` | ✅ | **202** ⚠️ | Спека: 200. Реальность: 202 |

</div>

### Отклонения от OpenAPI

| Эндпоинт | Ожидание | Реальность |
|----------|---------|------------|
| `POST /booking/` | 200 OK | **201 Created** |
| `DELETE /booking/{id}` | 200 OK | **202 Accepted** |
| `GET /booking/-1` (отрицательный ID) | 400 Bad Request | **404 Not Found** |

## Сервис: Room

- **Базовый URL**: `http://localhost:3001`
- **Swagger**: `http://localhost:3001/room/v3/api-docs`
- **Health**: `http://localhost:3001/room/actuator/health`

<div class="table-container">

| Метод | Путь | Назначение | Клиент | Требует токен | Статус | Примечания |
|-------|------|-----------|--------|:----------:|--------|-----------|
| GET | `/room/` | Все комнаты | `PublicRoomClient` | ❌ | **200** ✅ | Опциональные: `checkin`, `checkout` |
| GET | `/room/{id}` | Детали | `PublicRoomClient` | ❌ | **200** ✅ | — |
| POST | `/room/` | Создание | `PrivateRoomClient` | ✅ | **201** ✅ | Требует `roomPrice` >= 1 |
| PUT | `/room/{id}` | Обновление | `PrivateRoomClient` | ✅ | **202** ⚠️ | Спека: 200. Реальность: 202 |
| DELETE | `/room/{id}` | Удаление | `PrivateRoomClient` | ✅ | **202** ⚠️ | Спека: 200. Реальность: 202 |

</div>

### Отклонения от OpenAPI

| Эндпоинт | Ожидание | Реальность |
|----------|---------|------------|
| `GET /room/9999` (не найдено) | 404 | **500** |
| `GET /room/0` (невалидный ID) | 400 | **500** |
| `GET /room/-1` (отрицательный ID) | 400 | **404** |
| `POST /room/` поле `roomPrice` | опционально | **Required >= 1** |

### Сериализация
- Поля в **camelCase** (roomName, type, roomPrice, roomid)
- `null` → 400. Используется `exclude_none=True`

## Сервис: Message

- **Swagger**: `http://localhost:3006/message/v3/api-docs`
- **Health**: `http://localhost:3006/message/actuator/health`

<div class="table-container">

| Метод | Путь | Назначение | Клиент | Требует токен | Статус | Примечания |
|-------|------|-----------|--------|:----------:|--------|-----------|
| GET | `/message/` | Все сообщения | `PublicMessageClient` | ❌ | **200** ✅ | — |
| GET | `/message/count` | Кол-во | `PublicMessageClient` | ❌ | **200** ✅ | — |
| POST | `/message/` | Создание | `PublicMessageClient` | ❌ | **201** ⚠️ | Спека: 200. Реальность: 201 |
| GET | `/message/{id}` | Детали | `PublicMessageClient` | ❌ | **200** ✅ | **Публичный**, токен не нужен |
| PUT | `/message/{id}/read` | Прочитано | `PrivateMessageClient` | ✅ | **202** ⚠️ | Спека: 200. Реальность: 202 |
| DELETE | `/message/{id}` | Удаление | `PrivateMessageClient` | ✅ | **202** ⚠️ | Спека: 200. Реальность: 202 |

### Отклонения от OpenAPI

| Эндпоинт | Ожидание | Реальность |
|----------|---------|------------|
| `GET /message/{id}` | требует токен | **Публичный** |
| `GET /message/9999` (не найдено) | 404 | **500** |

### Схемы
- `MessageSchema`: messageid, name, email, phone, subject, description
- `MessageSummarySchema` (список): id, name, subject, read — поле `id`, не `messageid`
